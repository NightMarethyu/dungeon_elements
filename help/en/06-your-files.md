# Your files and other apps

Your campaign is a folder of ordinary files. You can back it up, put it in a synced folder, or edit it in another app at the same time.

## Editing in other apps

- The app watches the campaign folder. Notes changed, renamed or deleted in another app show up right away.
- If a note you have open changes outside the app, it reloads. If you have unsaved changes to it, the app asks which version to keep. Saving never overwrites another app's changes without asking.
- **View > Refresh File Tree** checks the folder again if anything looks out of date.

## Using Obsidian

Notes, links, fields and pictures are saved the way Obsidian expects, so you can open the campaign folder as an Obsidian vault.

## When a note has problems

If a note was changed in a way the app can't show as intended (a word in a number field, a broken link), it gets a ⚠ in the file tree. Nothing is changed for you: hover the ⚠ to see what's wrong, and click it for ways to fix it. The ⚠ in the status bar lists every note with problems.

## Saving

- **Ctrl+S** saves the note you're on, and **Ctrl+Alt+S** saves every note with unsaved changes.
- A tab with unsaved changes shows a dot, and the app asks before closing anything unsaved.

## Themes

Pick a color theme in the **View** menu. To make your own, copy a theme file into your themes folder (**Help > About** shows where it is), change its colors, and choose **View > Reload Themes**.
