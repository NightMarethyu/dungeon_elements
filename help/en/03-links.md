# Linking notes together

Links turn your notes into a wiki of your world. They are written like Obsidian's: `[[Name of the note]]`.

## Add a link

- Type `[[` and start typing a name. Notes that match are suggested under the editor; press **Tab** or click one to insert it.
- Or select some text and press **Ctrl+K** (**Edit > Insert Link**) to turn it into a link.
- In a link field, like an NPC's Location, type a name and press **Enter** to pick the first suggestion. A name that doesn't exist yet offers to make a new note in the right folder.

## Follow a link

- **Ctrl+click** a link in the editor, or click it in the reading view, to open the note.
- A link to a note that doesn't exist yet is dimmer. Following it makes the note.

## Other ways to write a link

- `[[Mira|the smuggler]]` shows "the smuggler" but opens Mira.
- `[[Mira#Appearance]]` opens Mira at the Appearance heading.
- `![[Mira]]` shows Mira's text inside this note, and `![[map.png]]` shows a picture.
- Notes can have other names: add an **Aliases** field, and `[[Jerry]]` will find the note named BBEG.

## Links that keep working

- Rename a note (in the app or in another app) and every link to it is updated.
- Links that look broken get a ⚠ in the file tree. Hover it to see why, and click it for ways to fix it.

## See where a note is linked from

At the end of a note in the reading view, **Linked from** lists every note that links to it, so an NPC shows the quests, places and journal entries they turn up in.
