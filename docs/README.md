# Website

This folder is the project website, [nightmarethyu.github.io/dungeon_elements](https://nightmarethyu.github.io/dungeon_elements/). GitHub Pages publishes it from `main` (**Settings > Pages > Deploy from a branch > main > /docs**).

- `index.html` is the whole page, and `style.css` its colors and layout, taken from the app's Light and Dark themes.
- `images` holds the screenshots (1200 by 800, taken in the Light theme) and the logo.
- There's no build step: change a file, push, and the page updates a minute or two later. To look at it first, open `index.html` in a browser.

[RELEASING.md](../RELEASING.md) step 6 lists what to change with each release.
